# Code of Conduct

MiCoKnowGraph is developed as part of BioHackathon Europe and the ELIXIR Microbiome Community. We want participation to be harassment-free and welcoming for everyone, whatever their background, identity, career stage or level of experience.

This project follows:

- the **BioHackathon Europe code of conduct** (see the event website, <https://biohackathon-europe.org/>), which applies to all project spaces during and around the event; and
- the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** for this repository and its issue tracker.

In short:

- be kind;
- assume good intent;
- make space for newcomers and for people whose first language is not English;
- critique ideas, not people.

## Reporting

Report unacceptable behaviour to the project co-leads privately, or to the BioHackathon Europe organisers. Reports are handled confidentially.
